# Alau Term

Alau Term — наш дипломный демопроект сайта о котельном оборудовании и его обслуживании в Казахстане. Мы хотим, чтобы посетитель мог найти нужный товар, посмотреть услуги и быстро связаться с компанией.

На сайте предусмотрены каталог оборудования и запчастей, страницы сервисных услуг, формы заявок и русская и казахская версии. В дипломной работе мы также описываем требования к сайту, его устройство и результаты проверки.

## Что уже есть здесь

В репозиторий добавлена [главная страница на русском языке](prototype/snapshot/ru/index.html). Это первый этап переноса материалов. Пока здесь нет общих стилей, скриптов и изображений, поэтому страница открывается без привычного оформления, а ссылки и формы могут не работать.

Файл взят из более раннего снимка сайта. Мы добавляем готовые материалы в GitHub по частям и отдельно будем фиксировать новые исправления, тестирование и документацию. Дата коммита показывает, когда файл появился в репозитории.
