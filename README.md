# Alau Term

Это репозиторий дипломного проекта Alau Term. Здесь поэтапно публикуется **ранее существовавший снимок публичного сайта** от 29 сентября 2026 года. Дата коммита означает дату импорта, а не дату написания исходного кода.

## Текущее состояние

Stage 1 содержит сохранённую русскую главную страницу: [`prototype/snapshot/ru/index.html`](prototype/snapshot/ru/index.html). Значения CSRF-токенов из HTML удалены перед публикацией. Папка `prototype/snapshot/` предназначена для архивного снимка сайта. Наличие полного backend, базы данных и работающих форм этим снимком не подтверждается.

Сейчас страница **не работает автономно**: общие стили, скрипты и изображения относятся к Stage 2. Ссылки вида `/static/...` требуют веб-сервера, который отдаёт `prototype/snapshot/` как корень сайта. Отправлять формы из архивного HTML не следует.

## План публикации снимка

| Stage | Содержимое |
| --- | --- |
| 1 | Русская главная страница (этот коммит) |
| 2 | Общие CSS, JavaScript и изображения |
| 3 | Русский каталог, товары и бренды |
| 4 | Русские страницы пользовательских сценариев |
| 5 | Русские страницы услуг и компании |
| 6 | Казахская версия |
| 7 | Инвентаризация снимка и проверка ограничений |

В исходных ZIP путь начинается с `alau-term-public/87.255.201.20:8000/`. Для репозитория этот префикс заменяется на `prototype/snapshot/`, поскольку `:` в имени папки несовместим с Windows. В именах CSS и JavaScript из ZIP часть после `?` — это строка версии URL, её нужно убрать из имени файла при импорте следующих этапов. Остальную структуру путей сохраняйте. Каждый следующий пакет проверяйте на секреты и персональные данные до публикации.

## Совместная работа

Участники используют собственные GitHub-аккаунты и отдельные ветки для новых изменений. Коммиты импорта не выдают старый код за работу, выполненную в дату загрузки. Новую документацию, исправления и тестирование фиксируйте отдельно с описанием проверки. Требования диплома, архитектура и инструкция запуска приложения будут добавляться после проверки исходного проекта.
