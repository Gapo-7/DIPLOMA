# Проверка сохранённого снимка

Мы сверили файлы после Stage 1–7 с `sitemap.xml` и `missing_urls.txt` из исходного комплекта. Проверку можно повторить из корня репозитория:

```bash
python scripts/audit_snapshot.py
```

Скрипт читает только локальные файлы. Он не обращается к исходному сайту и не проверяет отправку форм.

| Что проверили | Результат |
| --- | ---: |
| Адреса в sitemap | 2 252 |
| Страницы sitemap, сохранённые в репозитории | 1 234 |
| Отсутствующие страницы sitemap | 1 018 |
| Совпадение отсутствующих страниц с `missing_urls.txt` | Полное |
| HTML-файлы вне sitemap | 19 |
| Отсутствующие пути к статике | 9 |
| CSRF-поля с сохранённым значением | 0 |

Среди 19 HTML-файлов вне sitemap есть страницы категорий, входа, чата и ошибок сервера, а также `files/index.html` с ответом Not Found. Девять отсутствующих ресурсов — изображения из `/static/img/concept/`. Их список печатает скрипт. Мы не добавляли вместо них случайные картинки.

`download_summary.txt` и `README_RU.txt` оставлены как исходные файлы. Число файлов в сводке относится к скачанному снимку, включая фрагменты `.tmp`; в Git мы их не добавляли. Совпадение с sitemap подтверждает состав сохранённой копии, но не работоспособность backend, полноту перевода или корректность всех пользовательских сценариев. Корзина, оформление заказа и часть кабинета в исходном снимке возвращают ошибки; эти страницы требуют отдельной реализации и проверки.
