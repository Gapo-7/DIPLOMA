ПУБЛИЧНАЯ КОПИЯ САЙТА «АЛАУ ТЕРМ»

Источник: http://87.255.201.20:8000/

Это статическая копия страниц, которые сервер отдавал через HTTP.
Она не содержит исходный Python/Django-код, базу данных, переменные окружения,
пароли или настройки сервера.

Как открыть:
1. Распакуйте архив.
2. Откройте файл 87.255.201.20:8000/ru/index.html в браузере.

Ограничения:
- вход, регистрация, корзина, поиск и отправка форм без Django не работают;
- некоторые ссылки могут обращаться к исходному серверу;
- загрузка была остановлена после того, как исходный сервер начал возвращать 502;
- полный перечень URL находится в sitemap.xml;
- адреса, которые не удалось сохранить, перечислены в missing_urls.txt.

Для восстановления полноценного проекта нужен доступ к VPS/хостингу или
резервная копия с Django-проектом, базой данных и папкой media.
