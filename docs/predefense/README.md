## Что требует фактического подтверждения

- Устное согласование темы и функций с представителем Alau Term есть; запись с
  именем, датой и согласованным объёмом ещё нужно оформить.
- [Проект YouTrack ALAU](https://gapar1.youtrack.cloud/projects/ALAU) создан;
  реальные задачи `ALAU-1`–`ALAU-15` и распределение указаны в [плане](followup/youtrack-plan.md).
  Обозначения `ПЛАН-01` в исходном документе остаются историческими кодами плана.
- Интервью с представителями пользователей и отзыв руководителя ещё не проведены
  или не зафиксированы. Их результаты нельзя подменять предположениями.
- Для первой сдаваемой версии используется тег [`prob-period-1`](https://github.com/Gapo-7/DIPLOMA/tree/prob-period-1).
  Загружаемые материалы следует брать из этой версии репозитория.

Готовые бланки и план задач находятся в [папке followup](followup/README.md). Бланки не означают, что интервью, отзыв руководителя или замеры уже проведены.
