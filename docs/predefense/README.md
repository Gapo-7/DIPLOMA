# Материалы к 20 октября 2026 года

Полный документ на английском языке с предложением проекта, распределением работ,
обзором источников, сравнениями, требованиями, архитектурой, планом проверки и
сроками находится в `Alau_Term_pre_defense_20_October_2026_EN.docx`.
В нём рассматриваются публичный сайт и внутренняя CRM: продажи, ремонтные заявки,
назначение работников и контроль выездов.

Это предложенное распределение для подтверждения командой и руководителем. История
Stage 1–7 показывает отдельные вклады и взаимное ревью, но импорт статического
снимка не является готовой серверной реализацией.

- Устное согласование темы и функций с представителем Alau Term есть; запись с
  именем, датой и согласованным объёмом ещё нужно оформить.
- YouTrack пока не создан. Таблица задач в документе готова для переноса;
  обозначения `ПЛАН-01` и далее не являются ID YouTrack.
- Интервью с представителями пользователей и отзыв руководителя ещё не проведены
  или не зафиксированы. Их результаты нельзя подменять предположениями.
- Тег `pre-defense-1` создаётся после проверки содержимого `main` перед сдачей.
