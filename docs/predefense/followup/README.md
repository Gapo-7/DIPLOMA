# Alau Term — материалы для завершения предзащиты

Дата подготовки: 14 октября 2026 года. Репозиторий проекта: https://github.com/Gapo-7/DIPLOMA.

Этот пакет отделяет готовые проектные материалы от подтверждений, которые ещё нужно получить. Публичные страницы в GitHub — сохранённый снимок и прототип интерфейса. Рабочая CRM для администраторов и менеджеров, включая учёт выездов работников по ремонту, остаётся задачей разработки.

| Материал | Что с ним делать | Статус |
| --- | --- | --- |
| [customer-confirmation.md](customer-confirmation.md) | Дать представителю Alau Term проверить и подтвердить запись устного согласования | Черновик; письменного подтверждения нет |
| [interviews-and-baseline.md](interviews-and-baseline.md) | Записать реальные ответы менеджера и выездного работника, замерить текущий процесс | Форма; интервью и измерений нет |
| [youtrack-plan.md](youtrack-plan.md) | Сверять задачи и распределение с [проектом YouTrack](https://gapar1.youtrack.cloud/projects/ALAU) | Проект создан; задачи `ALAU-1`–`ALAU-15` открыты |

## До 20 октября

1. Подтвердить с компанией границы проекта и порядок учёта ремонтных выездов.
2. Зафиксировать хотя бы одно интервью с менеджером и, если возможно, с выездным работником.
3. Использовать созданный YouTrack-проект и связывать новые ветки/PR с реальными задачами.
4. Показать документы руководителю и записать фактические замечания.

## До 24 октября

Проверить документы и диаграммы, связать задачи с новыми ветками/PR и поставить тег контрольной версии после проверки. Тег не должен означать, что CRM уже готова.

**Правило:** пустые поля в формах ниже заполняются только после разговора или реального теста. Их нельзя представлять как проведённые интервью, одобрение руководителя или измеренный эффект.
