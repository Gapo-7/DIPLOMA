# Заметки об импорте снимка сайта

Исходные файлы находятся в семи ZIP-пакетах `ALAU_TERM_7_STAGES_BUNDLE.zip`. Это снимок публичного сайта от 29 сентября 2026 года, а не полный набор исходников приложения с серверной частью и базой данных.

При переносе файлов в репозиторий заменяйте префикс `alau-term-public/87.255.201.20:8000/` на `prototype/snapshot/`. Двоеточие в имени папки из архива несовместимо с Windows. В именах CSS и JavaScript удаляйте часть после `?`: она была строкой версии в URL, а не частью имени файла. Остальную структуру путей сохраняйте, чтобы ссылки между этапами совпали.

Перед загрузкой нового пакета проверьте, какие файлы уже есть в репозитории, и просмотрите добавляемые файлы на секреты и персональные данные. В Stage 1 из сохранённого HTML были убраны значения CSRF-токенов. Не считайте страницы с формами доказательством работы backend и не описывайте импорт старого снимка как новую разработку в день коммита.

В Stage 3 архив содержит 608 полных HTML-страниц и 10 файлов `.tmp`. Каждый `.tmp` — обрезанное начало уже имеющейся полной страницы, поэтому в репозиторий перенесены только 608 полных страниц. Из сохранённых форм удалены значения CSRF-токенов; остальные тексты страниц оставлены как в архиве.

После Stage 3 проверка 609 русских HTML-страниц (включая главную) нашла 8 ссылок на изображения, которых нет в комплекте, и 350 ссылок на отсутствующие страницы каталога или товаров. Это пробелы исходного снимка; соответствующие файлы не создавались искусственно.

В Stage 4 перенесены шесть страниц пользовательских сценариев. `cart` и `checkout` содержат исходный ответ 502, а `workspace` — Not Found. Они не показывают работающие интерфейсы. В трёх остальных страницах очищены значения CSRF-токенов.

В Stage 5 перенесены 15 русских страниц услуг и информации о компании. В них очищены 45 сохранённых значений CSRF-токенов. Все ссылки этих страниц на другие русские страницы ведут к уже перенесённым файлам. На странице подбора запчастей есть ссылка на отсутствующее в комплекте изображение `/static/img/concept/nameplate.webp`; файл не заменяли выдуманной картинкой.

В Stage 6 архив содержит 622 HTML-страницы казахской версии и 15 файлов `.tmp`. Каждый `.tmp` является точным обрезанным префиксом полной страницы из того же архива; эти фрагменты не импортированы. В HTML очищены 4 848 сохранённых значений CSRF-токенов. Остальное содержимое сохранено с нормализацией переводов строк в Git. Страницы `kk/cart`, `kk/checkout`, `kk/account` и `kk/workspace` содержат исходный ответ 502 Bad Gateway, а не рабочие интерфейсы. Импорт не подтверждает работу backend или полноту перевода.

Проверка Stage 6: CSS, JavaScript и логотип доступны; ссылки на девять изображений ведут к файлам, отсутствующим во всём комплекте. На страницах казахского каталога и товаров есть 358 уникальных отсутствующих адресов (3323 вхождений ссылок). Формы, поиск и действия корзины требуют отсутствующего backend. В `kk/chat` сохранён русский текст исходного снимка; полнота перевода не подтверждена. Для просмотра абсолютных путей `/static/` корнем HTTP-сервера должен быть `prototype/snapshot/`.

В Stage 7 файл `files/index.html` перенесён в `prototype/snapshot/files/`; он содержит исходную страницу Not Found. Четыре файла метаданных из корня архива сохранены без изменения в `docs/source-snapshot/`, поскольку они не находились внутри папки сервера `87.255.201.20:8000`. Итоговая сверка и её способ описаны в [отчёте](snapshot-audit.md).
