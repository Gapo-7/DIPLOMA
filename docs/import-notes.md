# Заметки об импорте снимка сайта

Исходные файлы находятся в семи ZIP-пакетах `ALAU_TERM_7_STAGES_BUNDLE.zip`. Это снимок публичного сайта от 29 сентября 2026 года, а не полный набор исходников приложения с серверной частью и базой данных.

При переносе файлов в репозиторий заменяйте префикс `alau-term-public/87.255.201.20:8000/` на `prototype/snapshot/`. Двоеточие в имени папки из архива несовместимо с Windows. В именах CSS и JavaScript удаляйте часть после `?`: она была строкой версии в URL, а не частью имени файла. Остальную структуру путей сохраняйте, чтобы ссылки между этапами совпали.

Перед загрузкой нового пакета проверьте, какие файлы уже есть в репозитории, и просмотрите добавляемые файлы на секреты и персональные данные. В Stage 1 из сохранённого HTML были убраны значения CSRF-токенов. Не считайте страницы с формами доказательством работы backend и не описывайте импорт старого снимка как новую разработку в день коммита.
